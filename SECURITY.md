# Security

## Supported versions

Security fixes are released only for the latest release `layers-YYYY-MM`.

## Reporting a vulnerability

Do not report a vulnerability in a public issue. Use the private report:
[Report a vulnerability](https://github.com/geokuk-community/geokuk-maps/security/advisories/new)
(Security tab → Advisories).

This covers the workflows, the scripts, a forged or corrupted layer file,
and a SHA-256 mismatch between `layers.json` and a release file.
Include the release tag, the file name and the steps to reproduce it.

The project is maintained by volunteers. We usually reply within a month.
If the report is confirmed, the fix is published as a new release on
[Releases](https://github.com/geokuk-community/geokuk-maps/releases)
and the report is published as a security advisory. If we reject the report,
we will explain why.

Errors in map content (for example a missing route) are not security issues.
Report them in the issues of the main repository
[geokuk](https://github.com/geokuk-community/geokuk/issues).
